## 📌 Featured Academic Repositories

### 🤖 [Recommender Systems](https://github.com/alu0101547619/Recommender-Systems)
High-performance C++ algorithmic suite implementing two core recommendation paradigms:
* **Collaborative Filtering:** User-user $k$-NN approach supporting Pearson Correlation, Cosine Distance, and Normalized Euclidean metrics, with Weighted Average and Difference-from-Mean predictions.
* **Content-Based Filtering:** Vector Space Model utilizing NLP techniques (Stopwords filtering, JSON-based Lemmatization), Logarithmic $\text{TF}$, Smoothed $\text{IDF}$, and normalized Cosine Similarity matrices.

### 💎 [Lenguajes y Paradigmas de Programación (LPP)](https://github.com/alu0101547619/LPP)
Advanced exploration of programming paradigms using **Ruby**:
* Domain-Specific Languages (DSLs) development.
* Object-Oriented Design (OOD) & Metaprogramming constructs.
* Functional programming patterns.
* Test-Driven Development (TDD) using RSpec.

### 🧠 [Knowledge Management in Organizations (KMO)](https://github.com/alu0101547619/KMO)
Frameworks and documentation covering organizational knowledge engineering, structured information systems, and knowledge transfer workflows.
